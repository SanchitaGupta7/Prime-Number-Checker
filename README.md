## 🧠 How It Works

A prime number is a number greater than 1 that has exactly two factors: **1 and itself**.

The application takes a number as input and checks whether it has any divisors other than 1 and the number itself. Based on the result, it displays whether the entered number is **prime** or **not prime**.

### Example

| Input | Result    |
| ----- | --------- |
| `2`   | Prime     |
| `7`   | Prime     |
| `13`  | Prime     |
| `10`  | Not Prime |
| `15`  | Not Prime |
